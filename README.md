### Sobre mim

Trabalho com IA de ponta a ponta: do treino do modelo à API que coloca ele em produção.

- **Machine Learning Engineer na águilahub** (remoto): chatbots com RAG para automação de atendimento, usando LangChain, Dify, OpenAI API e Claude API.
- **Iniciação científica na UFV:** segmentação de plantas daninhas com YOLO no dataset CoFly-WeedDB.
- **Monitor de Inteligência Artificial** na UFV e instrutor de minicursos de visão computacional e RAG.
- Antes, na **Garza Inteligência Financeira**: backend em FastAPI + PostgreSQL e segurança (RBAC, JWT, SSO com Entra ID, detecção de anomalias com ML).
- Graduando em **Sistemas de Informação**, UFV campus Rio Paranaíba (conclusão em dez/2026).
